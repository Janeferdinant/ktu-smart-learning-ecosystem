Model Answer Key
Q1. Differentiate between Method Overloading and Method Overriding in Java.
3 Marks

Evaluation Scheme & Solution:

Feature Method Overloading Method Overriding
Binding Compile-time (Static binding) Run-time (Dynamic method dispatch)
Signature Must differ in parameter type or count Must be identical in name and parameters
Inheritance Within the same class or child class Requires IS-A relationship between classes
Q2. Explain Dynamic Method Dispatch with a suitable Java code example illustrating runtime polymorphism.
14 Marks

Complete Java Implementation:

class Shape { void draw() { System.out.println("Drawing generic shape"); } } class Circle extends Shape { @Override void draw() { System.out.println("Drawing Circle with radius r"); } } class Rectangle extends Shape { @Override void draw() { System.out.println("Drawing Rectangle with length and breadth"); } } public class DynamicDispatchDemo { public static void main(String[] args) { // Superclass reference holding subclass object Shape s; s = new Circle(); s.draw(); // Calls Circle's draw() at runtime s = new Rectangle(); s.draw(); // Calls Rectangle's draw() at runtime } }

Mark Distribution: Concept explanation (4 Marks) + Class hierarchy with inheritance (4 Marks) + Main method dispatch demonstration (4 Marks) + Output (2 Marks) = 14 Marks.
