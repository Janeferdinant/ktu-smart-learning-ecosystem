📑 Solved Previous Year Question Paper: KTU Embedded Systems

Model Answer Key
Q1. What is the role of the Bit Set/Reset Register (BSRR) in STM32 GPIO control, and why is it preferred over ODR?
3 Marks

Evaluation Scheme & Solution:

Atomic Operation: The 32-bit GPIOx_BSRR register allows individual pin setting (bits 0–15) and resetting (bits 16–31) in a single atomic clock cycle. Writing to BSRR eliminates the need for read-modify-write software sequences on ODR, completely preventing race conditions when interrupts preempt pin toggles.

Q2. Write an embedded C program to configure GPIO Pin PC13 as output (connected to User LED) and toggle it every 500 ms using SysTick Timer interrupts on STM32.
14 Marks

Complete Embedded C Implementation:

#include "stm32f4xx.h" volatile uint32_t msTicks = 0; void SysTick_Handler(void) { msTicks++; } void delay_ms(uint32_t ms) { uint32_t start = msTicks; while ((msTicks - start) < ms); } int main(void) { // 1. Enable Clock for GPIOC via AHB1 peripheral bus RCC->AHB1ENR |= RCC_AHB1ENR_GPIOCEN; // 2. Set Pin PC13 to General Purpose Output Mode (MODER[27:26] = 01) GPIOC->MODER &= ~(3U << (13 * 2)); // Clear mode bits GPIOC->MODER |= (1U << (13 * 2)); // Output mode // 3. Configure SysTick to interrupt every 1 ms (168 MHz core clock) SysTick_Config(SystemCoreClock / 1000); while (1) { // Toggle PC13 atomically using BSRR if (GPIOC->ODR & (1U << 13)) { GPIOC->BSRR = (1U << (13 + 16)); // Reset pin } else { GPIOC->BSRR = (1U << 13); // Set pin } delay_ms(500); } }

Mark Distribution: RCC clock configuration (3 Marks) + GPIO MODER register bitmask setup (4 Marks) + SysTick timer configuration (4 Marks) + Main loop atomic toggle logic (3 Marks) = 14 Marks.
