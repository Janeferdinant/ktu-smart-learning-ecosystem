📑 Solved Previous Year Question Paper: KTU PECST521

Model Answer Key
Q1. Define Float (Slack time) in project scheduling. What is the float value for activities on the Critical Path?
3 Marks

Evaluation Scheme & Solution:

Total Float: The maximum duration by which an activity can be delayed without extending the overall project completion deadline.
Total Float = Late Start (LS) - Early Start (ES) = Late Finish (LF) - Early Finish (EF).

Critical Path Float: For all activities lying on the Critical Path, the total float is strictly Zero (0), meaning any delay in these activities immediately delays project delivery.

Q2. Explain the Basic and Intermediate COCOMO models. A software system is estimated to have 32 KLOC developed under Organic mode. Calculate the Effort and Development Time.
14 Marks

Complete Mathematical Solution:

1. Basic COCOMO Constants for Organic Mode:

a = 2.4, b = 1.05, c = 2.5, d = 0.38

2. Effort Calculation (E):

E = a × (KLOC)b = 2.4 × (32)1.05
E = 2.4 × 38.05 = 91.33 Person-Months (PM)

3. Development Time Calculation (TDEV):

TDEV = c × (E)d = 2.5 × (91.33)0.38
TDEV = 2.5 × 5.51 = 13.78 Months (~14 Months)

4. Average Staff Size:

Staff = E / TDEV = 91.33 / 13.78 = 6.62 ≈ 7 Engineers

Mark Distribution: COCOMO model classification theory (4 Marks) + Formula specification (3 Marks) + Step-by-step substitution (5 Marks) + Final effort, duration, and staff numbers (2 Marks) = 14 Marks.
