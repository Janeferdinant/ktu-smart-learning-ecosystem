📑 Solved Previous Year Question Paper: KTU PCADT502

Model Answer Key
Q1. Enumerate the four standard Denavit-Hartenberg (DH) parameters used in robotic link kinematic modeling.
3 Marks

Evaluation Scheme & Solution:

1. Link Length (ai): Distance between Zi-1 and Zi measured along Xi.
2. Link Twist (αi): Angle between Zi-1 and Zi measured about Xi.
3. Link Offset (di): Distance between Xi-1 and Xi measured along Zi-1 (variable in prismatic joints).
4. Joint Angle (θi): Angle between Xi-1 and Xi measured about Zi-1 (variable in revolute joints).

Q2. Derive the complete Forward Kinematics Transformation Matrix for a 2-Link planar revolute manipulator with link lengths L1 and L2 using DH parameters.
14 Marks

Detailed Model Derivation:

Link θi di ai αi
1 θ1 0 L1 0°
2 θ2 0 L2 0°
// Resulting Homogeneous Transformation Matrix T = A1 * A2: | cos(θ1+θ2) -sin(θ1+θ2) 0 L1*cos(θ1) + L2*cos(θ1+θ2) | | sin(θ1+θ2) cos(θ1+θ2) 0 L1*sin(θ1) + L2*sin(θ1+θ2) | | 0 0 1 0 | | 0 0 0 1 |

Mark Distribution: Frame assignment diagram (3 Marks) + DH Parameter Table (3 Marks) + Individual A1 and A2 transformation matrices (4 Marks) + Final Matrix multiplication and coordinate extraction (4 Marks) = 14 Marks.
