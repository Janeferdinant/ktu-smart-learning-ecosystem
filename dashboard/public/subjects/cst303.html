📑 Solved Previous Year Question Paper: KTU CST303

Model Answer Key
Q1. What is the "Count to Infinity" problem in Distance Vector Routing? Mention two solutions.
3 Marks

Evaluation Scheme & Solution:

Definition: In Distance Vector Routing (Bellman-Ford), when a link breaks, neighboring routers take iterations to realize unreachable nodes, gradually incrementing their hop counts up to infinity (defined as 16 in RIP).

Remedies:
1. Split Horizon: Do not advertise a route back to the neighbor from which it was learned.
2. Poison Reverse: Advertise broken links with an infinite metric (∞) to immediately purge routing loops.

Q2. Explain the Leaky Bucket and Token Bucket traffic shaping algorithms with diagrams and compare their burst handling capabilities.
14 Marks

Detailed Model Answer:

Attribute Leaky Bucket Algorithm Token Bucket Algorithm
Output Rate Strictly Constant (No bursts allowed) Allows controlled bursts up to token limit
Packet Dropping Drops excess packets when buffer overflows Discards tokens, retaining packets in queue
Ideal Use Case ATM constant-bitrate audio/video streams Bursty IP web traffic and interactive games
