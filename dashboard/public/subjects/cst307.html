📑 Solved Previous Year Question Paper: KTU CST307

Model Answer Key
Q1. State the Apriori Property (Downward Closure Property) and explain how it reduces search space.
3 Marks

Evaluation Scheme & Solution:

Apriori Property: "All non-empty subsets of a frequent itemset must also be frequent."

Search Space Pruning: Conversely, if an itemset is infrequent, all of its supersets are guaranteed to be infrequent and are pruned immediately without counting candidate support against the database, drastically cutting combinatorial complexity from O(2^d).

Q2. Given a transactional database with 5 transactions, apply the Apriori algorithm with Minimum Support = 2 to find all frequent itemsets and derive association rules with Minimum Confidence = 60%.
14 Marks

Step-by-Step Model Answer:

Step 1: Scan DB to generate C1 and L1 (min_sup = 2):

L1 = { {Bread: 4}, {Milk: 4}, {Diaper: 4}, {Beer: 3}, {Cola: 2} } — All items meet min_sup ≥ 2.

Step 2: Generate Candidate C2 = L1 ⋈ L1 and prune to L2:

L2 = { {Bread, Milk: 3}, {Bread, Diaper: 3}, {Bread, Beer: 2}, {Milk, Diaper: 3}, {Milk, Beer: 2}, {Diaper, Beer: 3} }

Step 3: Generate C3 = L2 ⋈ L2 and prune to L3:

Candidate {Bread, Milk, Diaper}: Subsets {Bread, Milk}, {Bread, Diaper}, {Milk, Diaper} are all in L2. Support in DB = 2.
Candidate {Bread, Diaper, Beer}: Support in DB = 2. Subsets frequent. Hence L3 = { {Bread, Milk, Diaper}, {Bread, Diaper, Beer} }.

Step 4: Association Rule Derivation:

Rule: {Beer} ⇒ {Diaper}: Confidence = Support(Beer, Diaper) / Support(Beer) = 3 / 3 = 100% (Valid since ≥ 60%).
Rule: {Milk} ⇒ {Bread}: Confidence = Support(Milk, Bread) / Support(Milk) = 3 / 4 = 75% (Valid).

Mark Distribution: L1 computation (3 Marks) + L2 computation & candidate pruning (4 Marks) + L3 generation (4 Marks) + Association rules with confidence formulas (3 Marks) = 14 Marks.
